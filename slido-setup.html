Slido polls for Session 1

Create one Slido event for the session and add these polls in this order, so you only ever activate the next one. Then put the event link and code into assets/config.js. This page is not linked from the participant pages.

Useful settings: allow anonymous participation, and switch on Q&A for the whole event so questions can come in at any time. If you present from PowerPoint, the Slido add-in lets you insert any of these polls as a slide in the deck, next to the matching slide.

Teachable Machine

6In one word: what did your model really learn to look at? Word cloud
Open it once most groups have posted to the Moodle forum. Expect "background", "colour", "fur", "ears", "grass". Very few clouds say "cat".

Moodle forum for the failures

Forum type Standard forum displayed in a blog-like format
Each group starts its own discussion, and the first post of every discussion shows on one page, so the forum reads as a gallery during the debrief.
Attachments
Set the maximum number of attachments to at least 3 and check the maximum attachment size allows phone screenshots (5MB is plenty).
Picture sets
One zip per set, each containing a Cats folder and a Dogs folder. Smaller images (around 400 to 600px wide) train noticeably faster on tablets.
Debrief
Pick three posts: one where the prediction was right and well explained, one cross-test where the picture fooled one model but not another, and one impostor with very high confidence.
